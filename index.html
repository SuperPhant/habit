习惯记录

第一次在这台设备上使用，需要一把 GitHub 密钥，用来下载 App 和同步数据。密钥只保存在这台设备上。

iPhone 请先添加到主屏幕

Safari 和主屏幕上的 App 是分开保存数据的：在 Safari 里设置的密钥，主屏幕 App 里用不了。所以请先：

  1. 点 Safari 底部（或地址栏旁）的「分享」按钮（方框带向上箭头）。
  2. 往下找到「添加到主屏幕」，点「添加」。
  3. 回到手机桌面，点「习惯记录」图标打开，再在里面扫码或粘贴密钥。

粘贴密钥

还没有密钥？在电脑上生成（约 1 分钟）

  1. 在电脑浏览器打开 github.com，先确认右上角头像是 SuperPhant。如果不是：点头像 → 切换账号，或退出后用 SuperPhant 登录。
  2. 点下面的「去 GitHub 生成密钥」。名称、说明、所属账号（SuperPhant）、有效期（不过期）、权限（Contents：Read and write）都已经填好，不用改。
  3. 在 Repository access 里选 Only select repositories，在下拉框中勾选 habit-tracker 和 habit-tracker-data 两个仓库。
  4. 拉到页面最下面，点 Generate token（如果弹出确认框，再点一次）。
  5. 点密钥旁边的复制按钮。这把密钥只显示这一次。
  6. 回到这个页面，点「粘贴」，再点「验证并开始」。

在手机上使用

iPhone：用 Safari 打开 → 点「分享」→「添加到主屏幕」→「添加」→ 从桌面的「习惯记录」图标打开 →「扫码导入密钥」，扫电脑上显示的二维码。

安卓：用 Chrome 打开 → 点右上角「⋮」→「安装应用」或「添加到主屏幕」→ 从桌面图标打开 →「扫码导入密钥」，扫电脑上显示的二维码。

电脑上的二维码在：习惯记录 → 设置 → 在手机上使用 → 显示二维码。扫码时别让别人拍到电脑屏幕。

密钥只保存在这台设备的浏览器里，不会上传到别的地方，页面上始终打码显示。
